# Third-party artwork

Assets and geometry in this repo that came from somewhere else, and the terms
they came under. Keep this list in step with the app's credits.

## Lucide — ISC

`src/lib/shapeLibrary.ts` embeds the path geometry of 1,776 Lucide icons and
their search keywords, generated from the `lucide-static` package. Lucide is
ISC-licensed; the notice is in `LUCIDE-LICENSE.txt` and must travel with the
copies. No Lucide package ships at runtime — only the generated data.

<https://lucide.dev>

## Icons8

`public/blooms/`, `public/relax/` and `public/flowers/` hold PNG artwork from
the Icons8 catalogue, used for the Stress Reliefer's bloom, pond and drift
effects. Icons8 assets carry Icons8's own licence — keep the attribution in the
app's credits.

<https://icons8.com>
